# TravelSmart

## Project Documentation

### Overview
TravelSmart is a comprehensive travel planner application designed to assist users in exploring multi-modal transport options. Whether you're traveling by bus, train, or airplane, TravelSmart provides cost comparisons and layover routing to help you make informed decisions about your travel plans.

### Features
- **Multi-Modal Transport Options:** Choose from various transport means including buses, trains, and flights.
- **Cost Comparison:** Compare the costs of different transport modes to find the most economical option.
- **Layover Routing:** View potential layovers and their durations, optimizing your travel time.

### Getting Started
1. Clone the repository:
   ```bash
   git clone https://github.com/rahulkiran1905/travelsmart.git
   ```
2. Install the required dependencies:
   ```bash
   npm install
   ```
3. Run the application:
   ```bash
   npm start
   ```

### Technologies Used
- Frontend: React.js
- Backend: Node.js
- Database: MongoDB
